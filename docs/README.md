# Dokumentation

Die aktuelle fachliche Grundlage steht in [Anforderungen](produkt/anforderungen.md), [Datenmodell](produkt/datenmodell.md) und den [bestätigten Entscheidungen](entscheidungen/0001-fachlicher-kern.md). Der [Implementierungsstand](status.md) beschreibt die tatsächlichen Fähigkeiten des Prototyps. [Betrieb und Synchronisation](architektur/betrieb-und-synchronisation.md) ist eine Diskussionsgrundlage, keine beschlossene Architektur.

Die [Referenzunterlagen](referenz/README.md) enthalten die vollständigen früheren Konzepte. Sie bleiben nachvollziehbar erhalten. Bei Abweichungen gilt eine später ausdrücklich bestätigte Entscheidung vor einem älteren Entwurf. Der Prototyp allein macht einen Vorschlag nicht verbindlich.

| Kürzel | Bedeutung |
|---|---|
| B | Im Gespräch bestätigt beziehungsweise ausdrücklich angefordert |
| V | Vorschlag zur Ausgestaltung, noch zu bestätigen |
| O | Offene Entscheidung |

Die Kennzeichnung beschreibt fachlichen Beschlussstatus. Sie ist unabhängig davon, ob eine Funktion im Prototyp bereits sichtbar ist.
